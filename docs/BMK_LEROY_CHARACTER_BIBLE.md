# BADMAN KOMBAT™ — LEROY CHARACTER BIBLE

Status: CANON CONTROL DOCUMENT
Character ID: `BMK-CHR-LEROY-001`
Era anchor: Kingston, Jamaica — 1987
Purpose: Preserve one recognisable Leroy across comic, game, cinematics, trailers, promotion and future media.

## 1. Governing rule

Leroy may change state. Leroy may not change identity.

Rain, sweat, injury, expression, lighting, camera angle, story tension and wardrobe state may vary when the story requires them. His face structure, apparent age, physique, hairstyle/hairline, skin tone, distinguishing features, body proportions, core silhouette and signature identity must remain recognisably the same.

No production asset is canonical merely because it looks attractive. It becomes canonical only after side-by-side continuity review.

## 2. Authority hierarchy

1. User-approved visual reference material
2. This Character Bible
3. Approved production model sheet / hero renders
4. Game model, comic panels, cinematic renders and marketing artwork
5. Legacy prototype imagery and old prompts — reference only

Legacy material may inform exploration but may not overwrite the current canon.

## 3. Historical evidence — not automatic canon

Earlier prototype material described Leroy as a muscular Black Jamaican fighter with dreadlocks, a white sleeveless vest and red hand wraps. Those details are retained only as historical design evidence until individually confirmed by approved visual reference material.

The old prototype also drifted into generic “Rasta warrior”, mystical-power and cyberpunk language. Those elements are explicitly NOT authoritative for Leroy’s current character identity.

## 4. Identity lock

The following features are immutable after final visual approval:

- facial bone structure
- eye shape and spacing
- nose shape
- mouth/lip structure
- jawline and chin
- apparent age
- skin tone and undertone
- hairline
- hairstyle / dreadlock pattern if approved
- facial hair pattern if approved
- height relationship to other principal characters
- shoulder width and torso proportions
- arm/leg proportions
- fighter build and body mass
- scars, marks or other distinguishing features once approved
- core silhouette at distance

The acceptance question is simple:

> Could a player recognise Leroy from silhouette, profile and close-up without seeing his name?

If not, the asset fails.

## 5. Cultural presentation rules

Leroy is a Jamaican man and a specific character, not a collection of shorthand symbols.

Do not communicate Jamaican identity by automatically adding:

- cannabis imagery
- red/gold/green clothing everywhere
- random Rastafari symbols
- exaggerated patois text on clothing
- generic “mystical Rasta” iconography
- tourist-souvenir styling
- cyberpunk neon simply because the old prototype used it

Culture should emerge through era, neighbourhood, speech, relationships, music, history, clothing choices, environment, behaviour and story.

## 6. Visual target

Target: realistic premium action-game character quality that can survive:

- mobile comic close-up
- cinematic 16:9 crop
- game character select portrait
- full-body gameplay model reference
- key art / poster crop
- eventual physical collectible reference

The desired impression is not “generated fighter artwork”. It is “this is Leroy”.

## 7. Required master model sheet

Before broad content production, approve a master model sheet containing:

1. front portrait — neutral expression
2. 3/4 portrait
3. left profile
4. right profile
5. full-body front
6. full-body back
7. fighting stance
8. relaxed standing silhouette
9. expression set: neutral / amused / angry / focused / hurt
10. hand / wrap / accessory details if present
11. wardrobe callouts
12. height / build notation
13. material / fabric notes
14. “MUST NEVER CHANGE” strip

This sheet becomes the principal production reference for all future media.

## 8. Kingston ’87 wardrobe state

Working wardrobe ID: `BMK-WRD-LEROY-K87-STREET-001`

Wardrobe must be plausible for Kingston in 1987 and consistent across BMK #0 scenes 03–05 unless an explicit story event changes it.

No futuristic armour, glowing circuitry, tactical sci-fi harnesses or contemporary fashion contamination.

Exact clothing colours and garment construction remain pending final visual approval.

## 9. Three-scene continuity gate

### A. LEROY-RAIN
Scene: `BMK-COMIC-00-S03`

Required state:
- rainy Kingston street
- wet clothing / skin permitted
- serious but not exaggerated expression
- environment-light reflections permitted

Must preserve canonical identity completely.

### B. LEROY-DANCE
Scene: `BMK-COMIC-00-S04`

Required state:
- crowded sound-system environment
- stronger warm/practical lighting variation permitted
- movement and social context may alter expression/posture

Must be immediately recognisable as the same Leroy from LEROY-RAIN.

### C. LEROY-CONFRONTATION
Scene: `BMK-COMIC-00-S05`

Required state:
- tighter crop / confrontation close-up
- sweat, rain, tension and minor injury permitted
- expression may be more intense

Must remain the same face and body identity as the previous two scenes.

## 10. Side-by-side acceptance test

Review the three continuity images simultaneously.

PASS only if all reviewers can answer YES to all of the following:

- Same face?
- Same apparent age?
- Same hair/hairline?
- Same skin tone?
- Same body proportions?
- Same distinguishing marks?
- Same wardrobe continuity?
- Same core silhouette?
- No stereotype drift?
- No cyberpunk contamination?

A visually stronger image still fails if it depicts a different Leroy.
