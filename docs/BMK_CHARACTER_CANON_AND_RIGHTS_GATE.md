# BMK CHARACTER CANON + RIGHTS GATE

## Decision
The supplied visual references contain useful BMK DNA: heavyweight human scale, martial-arts cinema composition, Kingston street atmosphere, an underwater/creature scale reference, existing BMK roster concepts, and two photographic portrait references intended for character development.

They are references, not a licence to reproduce third-party protected characters or identifiable people without permission.

## Canon tiers
### Tier A — BMK originals: build these
- Leroy — hero priority. Original BMK fighter. Human, heavyweight, mature, Jamaican/Kingston story logic, believable martial movement.
- Asha — original BMK fighter. Develop as a complete person, not a roster archetype.
- Elder Zion — original BMK character. Spiritual/mentor dimension must avoid caricature.
- Sifu Drone — original BMK concept only if visual design is independently developed.
- Marcus and other BMK-original opponents/witnesses already documented.

### Tier B — consented real-person inspired characters
Photographic references can become game characters only when the depicted person has granted the project appropriate likeness/voice/performance rights. Preserve a written release in the production rights register. A consented character may be recognisable by design; otherwise create an original composite that does not reproduce the person's likeness.

One supplied portrait is presented in project artwork as a Sound Architect. Treat that role as a potentially powerful in-world character/system role, but obtain likeness permission before a recognisable model is produced.

### Tier C — inspiration only, never ship as copied characters
References labelled with third-party franchise characters (for example an assassin character or extraterrestrial hunter) are mood/archetype references only. Do not use their names, likenesses, costumes, signature props, logos, backstory, dialogue or confusingly similar visual designs in BMK. Replace them with independently authored BMK characters.

The vintage martial-arts poster is a composition/era reference only. Do not reproduce its actor likeness, title treatment or protected artwork.

The giant-octopus image is a scale/tension reference. Any BMK creature/encounter must be independently designed and should not reproduce the source image.

## Character Gate
No fighter is capture-approved until all are true:
1. identity sheet and original backstory approved
2. rights status green
3. front/side/back design approved
4. face close-up survives scrutiny
5. hands/feet/anatomy believable
6. dark-skin material reads correctly across warm/cool/rain lighting where applicable
7. cloth/hair/accessories behave credibly
8. production rig and deformation pass
9. idle, walk, guard, light, heavy, hit, knockdown pass without foot sliding
10. in-engine silhouette is recognisable with HUD hidden

## Rights register fields
For every hero/named character record:
- character_id
- original / licensed / consented-likeness
- creator/source
- reference images
- likeness release status
- voice/performance release status
- music/brand marks visible in references
- restrictions
- approval date
- evidence location

## Production order
Leroy → Marcus → Asha → 2 hero witnesses → Elder Zion → remaining characters.

No roster expansion should steal resources from getting Leroy and Marcus to believable-human quality.
